# ResearchOS – Multi-Agent Research System

ResearchOS is a Multi-Agent AI Research System that takes a research topic, searches the web, extracts useful information, generates a structured research report, and reviews the report.

## Live Demo
Deployed using Render
Link : https://multi-agent-system-dbpo.onrender.com

## Features

- Web search using DuckDuckGo
- Webpage content extraction
- AI-generated research reports
- AI-based report evaluation
- Streamlit user interface
- Groq LLM integration
- Render deployment

## Technologies Used

Python, LangChain, Groq, Streamlit, DuckDuckGo Search, BeautifulSoup, Requests

## Project Workflow

Research Topic  
↓  
Search Agent  
↓  
Reader Agent  
↓  
Writer  
↓  
Critic  
↓  
Final Research Report
 ## Environment variables
create a .env file in the project folder GROQ_API_KEY = your api key
